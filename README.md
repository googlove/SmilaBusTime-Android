# SmilaBusTime (Android)

Зручний та швидкий застосунок розкладу міських та приміських автобусів міста Сміла (Черкаська область), переписаний рідною мовою на Kotlin та Jetpack Compose.

## 🚌 Основні можливості

- **Усі міські та приміські маршрути**:
  - Міські маршрути: №3, 4, 5, 17, 30, 32, 34, 39, 40, 41, 48, 49 (ціна 20 грн).
  - Приміські маршрути: №302 (до Черкас), 309, 155, 154, 153, 152, 151, 150, 141, 140, 139, 137, 136, 129, 126, 123 з актуальними цінами та примітками.
- **Відлік найближчого рейсу**:
  - Розрахунок часу до найближчого автобуса в реальному часі («через 10 хв», «о 14:15»).
- **Детальний розклад та зупинки**:
  - Перемикач напрямків (Прямий / Зворотній).
  - Інтерактивні зупинки з часом відправлення та графіком робочих днів.
  - Можливість відкрити маршрут на картах Google.
  - Нагадування про виїзд автобуса.
- **🧭 Планувальник поїздки**:
  - Пошук прямих рейсів між обраними зупинками («Звідки» та «Куди»).
  - Швидкі підказки популярних зупинок (АС-2, Центр, Школа №3, Пушка, Вокзал тощо).
  - Розрахунок часу посадки, прибуття та тривалості в дорозі.
- **⭐ Обрані маршрути**:
  - Швидкий доступ до улюблених автобусів, сортування на початку списку.
- **ℹ️ Інформаційний довідник**:
  - Тарифи на проїзд та перелік пільгових категорій.
  - Попутка Сміла — Черкаси (ціни, зупинки, спільноти Telegram та Viber).
  - Посилання на Telegram-бот @SmilaBusTime_bot та зв'язок з розробником.
- **Теми оформлення**:
  - Підтримка світлої та темної теми зі зручним перемикачем у шапці.

## 🛠️ Технологічний стек

- **Мова**: Kotlin 2.2
- **UI**: Jetpack Compose, Material Design 3
- **Архітектура**: Clean MVVM + Repository pattern
- **Складання**: Gradle 9.3, Android Gradle Plugin (AGP) 9.1.1
- **Мінімальна версія Android**: Android 8.0 (API 26+)
- **Цільова версія Android**: Android 16 (API 36)
